# Original Batch CSVs

These 42 CSVs are the original batch files, moved here without changing their contents. They preserve historical questions, answer choices, difficulty ratings, duplicate full-batch/split-file copies, and the mixed Bible/space batches.

For videos, use the curated [`master_trivia.csv`](../master_trivia.csv) or a file from [`sets/`](../sets/). The archive includes unrelated topics and questions that were corrected or excluded during review.

The separate [`sample_of_5_trivia_questions.csv`](../sample_of_5_trivia_questions.csv) remains the packaging demo. All 43 original inputs are accounted for in [`audit/source_index.csv`](../audit/source_index.csv).
