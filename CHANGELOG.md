## 0.1.1 — Unreleased candidate

- Add Windows x64 desktop packaging with bundled source-built FFmpeg/ffprobe,
  fonts, sample questions, license/source materials, and package verification.
- Add Microsoft Store MSIX packaging and CI artifact generation with the
  reserved Trivia Countdown identity. Store package version `1.0.1.0` is
  tracked independently from the app version.

- Improve Windows path, subprocess, cancellation, and output-replacement handling.

Windows installation qualification, source/license approvals, MSIX certification,
and Store publication remain pending. This entry does not announce a download.
